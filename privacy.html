시행일: 2026-11-03

"웃참주의 YouTube 연결"(이하 앱)은 YouTube 채널 웃참주의 운영자 본인만 사용하는 개인용 도구입니다.

접근하는 정보

앱은 Google OAuth로 운영자 본인의 YouTube 계정에 접근 권한을 받아, 본인 채널의 동영상 업로드, 동영상 정보(제목·설명·태그) 수정, 재생목록 관리, 채널 통계 조회에만 사용합니다.

저장과 공유

발급된 인증 토큰은 운영자 본인의 컴퓨터에만 저장됩니다. 앱은 어떤 정보도 제3자에게 판매하거나 공유하지 않으며, 별도 서버에 수집하지 않습니다.

권한 취소

언제든지 Google 계정 권한 페이지에서 앱의 접근 권한을 취소할 수 있습니다.

앱이 Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
